## Weekly Programs

### Week 1 — HTML

Basic HTML programs covering:

- Headings and paragraphs
- Lists
- Tables
- Forms
- Links
- Images
- Multimedia
- Static web page design

### Week 2 — CSS

CSS programs covering:

- Selectors
- Colors
- Fonts
- Text styling
- Backgrounds
- Layouts
- Responsive design
- Inline CSS
- Internal CSS
- External CSS

### Week 3 — JavaScript

JavaScript programs covering:

- Variables and data types
- Functions
- Events
- DOM manipulation
- Form validation
- Interactive web pages

### Week 4 — Advanced JavaScript

Programs covering:

- Event handling
- Dynamic page manipulation
- Form validation
- JavaScript-based interactions

### Week 5 — Web Applications

Programs integrating HTML, CSS, and JavaScript.

Topics include:

- Form-based applications
- Input validation
- Regular expressions
- Dynamic web pages
- Client-side processing

### Week 6 — XML, DTD and XML Schema

Programs covering:

- Creating XML documents
- Book information using XML
- DTD validation
- XML Schema (XSD)
- XML data types
- XML document structure

### Week 7 — XSLT

Programs covering:

- XML documents
- XSLT
- XML-to-HTML transformation
- Displaying XML data in tables

### Week 8 — JDBC

Java Database Connectivity programs covering:

- Database connection
- Creating database tables
- Inserting records
- Retrieving records
- Updating records
- Deleting records
- CRUD operations using Statement

### Week 9 — JDBC PreparedStatement

Programs covering:

- Product database management
- Database connectivity
- Inserting product information
- Retrieving product information
- Updating product information
- Deleting product information
- CRUD operations using PreparedStatement
