Web Technology Weekly Programs
Web Technologies Lab Assignment

This repository contains the weekly programs and lab assignments completed as part of the Web Technologies course.

The programs cover client-side web development, XML, database connectivity, server-side programming, servlets, sessions, cookies, and JSP.
